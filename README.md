# 🎉 Event Management System

## Overview

The Event Management System is a C# console application that enables users to manage different types of events through an interactive menu-driven interface.

Users can create Workshops and Seminars, view all events, and navigate the application using a simple console menu.

The project demonstrates fundamental Object-Oriented Programming concepts and problem-solving using C#.

---

# Project Objective

To strengthen my understanding of C# programming, Object-Oriented Programming, collections, methods, and menu-driven application development.

- View All Events
