# Event Management System

## Overview
A console-based Event Management System developed in C# that allows users to manage different types of events through a simple menu-driven interface.

## Features
- Add Workshop
- Add Seminar
- View All Events
- Exit Application

## Technologies
- C#
- .NET
- Object-Oriented Programming
- Git
- GitHub

## Concepts Demonstrated
- Classes and Objects
- Encapsulation
- Methods
- Collections
- Menu-driven programming
- Clean code principles
